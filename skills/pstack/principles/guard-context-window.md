# Guard the Context Window

**Trigger:** Use when outputs, files, or fan-out threaten coordinator focus.

Route bulk search and long logs to bounded agents, preserve raw artifacts outside chat, and return structured evidence pointers. Keep the main context for judgment and reconciliation. Compression must retain objective, acceptance, provenance, contradictions, and limitations.

## Application record

When this principle materially changes a decision, record the concrete choice and evidence in `pstack_decision`. Do not cite a principle as decoration; state what alternative it ruled out or what structure it introduced.
