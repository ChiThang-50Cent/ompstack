# ompstack

Experimental Oh My Pi (OMP) plugins.

| Plugin | Description |
|---|---|
| [`omp-merge-ready`](omp-merge-ready/) | Drive an intent to a merge-ready branch/PR with fail-closed evidence gates |

Install:

```sh
omp plugin marketplace add ChiThang-50Cent/ompstack
omp plugin install omp-merge-ready@ompstack
```
