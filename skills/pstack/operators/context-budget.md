# Operator: Guard the context window

Treat the coordinator context as scarce judgment capacity.

- Send broad search, long logs, large files, and matrix work to bounded agents.
- Keep raw artifacts in files; return structured summaries with pointers.
- Read targeted ranges rather than whole files unless small.
- Do not paste duplicate source into multiple prompts.
- Reuse frozen briefs, schemas, and acceptance instead of paraphrasing them differently.
- Summarize settled facts; preserve unresolved contradictions and evidence pointers.
- Start a pickup checkpoint before context pressure erodes the objective or provenance.

Compression must not erase the exact artifact, decision rule, acceptance, or limitations.
