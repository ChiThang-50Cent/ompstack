# Encode Lessons in Structure

**Trigger:** Use when the same instruction or failure recurs.

Turn the lesson into a type, lint, schema, script, test, metadata flag, runtime gate, template, or reusable skill. Prose reminders decay and consume context. Structural enforcement should target objective invariants; keep subjective judgment in review rather than brittle regex gates.

## Application record

When this principle materially changes a decision, record the concrete choice and evidence in `pstack_decision`. Do not cite a principle as decoration; state what alternative it ruled out or what structure it introduced.
