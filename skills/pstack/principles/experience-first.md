# Experience First

**Trigger:** Use for product, UX, and feature-scope tradeoffs.

Start from the user or caller outcome, including failure experience, latency, clarity, and recovery. Implementation convenience is a constraint, not the goal. Resolve measurable experience questions with prototypes and observation; reserve genuine value choices for product judgment.

## Application record

When this principle materially changes a decision, record the concrete choice and evidence in `pstack_decision`. Do not cite a principle as decoration; state what alternative it ruled out or what structure it introduced.
