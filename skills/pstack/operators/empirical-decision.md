# Operator: Empirical decision

Before asking "which approach?", classify the fork.

- **Observable fact:** behavior, compatibility, timing, layout, output, capacity, benchmark separation. Build the smallest discriminating experiment.
- **Product preference/value:** desired experience, policy, audience, acceptable tradeoff. Use provided goals; ask only when no reversible default is covered.
- **Irreversible/high-consequence authorization:** deploy, destructive change, shared force-push, customer/public communication. Pause.

For experiments, write hypotheses, controlled variable, metric/observation, threshold, sample plan, and decision rule before results. Store raw evidence. Ambiguous data means INCONCLUSIVE, not a forced choice.
