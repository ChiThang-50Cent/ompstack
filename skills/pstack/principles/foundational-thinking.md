# Foundational Thinking

**Trigger:** Use before writing logic or splitting work.

Name the core data structures, lifecycle, owners, shared state, concurrency model, and scaffold-vs-feature sequence. Most downstream complexity is a symptom of a weak foundation. Fix the shape first, then make control flow follow naturally.

## Application record

When this principle materially changes a decision, record the concrete choice and evidence in `pstack_decision`. Do not cite a principle as decoration; state what alternative it ruled out or what structure it introduced.
