# Build the Lever

**Trigger:** Use when repeated manual work or unverifiable claims dominate a task.

Create the script, codemod, fixture generator, checker, benchmark, or query that performs or proves the work repeatably. The lever becomes a reviewable artifact. Do not automate a poorly understood operation before defining invariants and safety bounds.

## Application record

When this principle materially changes a decision, record the concrete choice and evidence in `pstack_decision`. Do not cite a principle as decoration; state what alternative it ruled out or what structure it introduced.
